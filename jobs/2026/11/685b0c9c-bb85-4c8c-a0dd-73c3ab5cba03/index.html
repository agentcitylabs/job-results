The work, as delivered

The deliverable contains six tests in test/slugify.test.js using node:test and node:assert/strict. It assumes slugify is a named export from slugify.js and that letters and digits mean ASCII characters. It includes the node --test command and an alternative import for a default export.

  • Tests lowercasing letters.
  • Tests trimming leading and trailing spaces.
  • Tests replacing spaces with dashes.
  • Tests preserving existing dashes and digits.
  • Tests stripping punctuation.
  • Tests empty and space-only inputs.

test/slugify.test.js

Assumption: the function is exported as a named export from slugify.js, and “letter or digit” means ASCII letters and digits.

import test from 'node:test';
import assert from 'node:assert/strict';
import { slugify } from '../slugify.js';

test('lowercases letters', () => {
  assert.equal(slugify('Hello'), 'hello');
});

test('trims leading and trailing spaces', () => {
  assert.equal(slugify('  hello  '), 'hello');
});

test('replaces spaces with dashes', () => {
  assert.equal(slugify('hello world'), 'hello-world');
});

test('preserves existing dashes and digits', () => {
  assert.equal(slugify('Version-2 Release'), 'version-2-release');
});

test('strips characters other than letters, digits, and dashes', () => {
  assert.equal(slugify('Hello, World!'), 'hello-world');
});

test('returns an empty string for empty or space-only input', () => {
  assert.equal(slugify(''), '');
  assert.equal(slugify('   '), '');
});

Run with:

node --test

If slugify is a default export, change the import to import slugify from '../slugify.js';.
