# SOP: New Hire’s First Day

**Purpose:** Give every new hire a welcoming, consistent first day and the access and context they need to begin work safely.  
**Applies to:** All new employees at the agency.  
**Owners:** The new hire’s manager coordinates the day; People/Operations handles paperwork and logistics.

## First-day steps

| When | Step | Owner |
|---|---|---|
| Before arrival | Confirm the start time, location or video link, schedule, and who will greet the new hire. Prepare their workspace, computer, accounts, and any required paperwork. | People/Operations |
| 9:00 | Welcome the new hire, show them around, introduce nearby teammates, and explain practical details such as breaks, lunch, and building access. For remote hires, give a brief virtual orientation. | Manager or assigned buddy |
| 9:30 | Complete employment forms and confirm payroll, emergency contact, and any required policy acknowledgments. Share where to find the employee handbook and agency policies. | People/Operations |
| 10:15 | Set up and test the computer, email, messaging, calendar, file storage, project-management platform, and design tools needed for the role. Confirm access is appropriate to the hire’s work. | IT or designated operations owner |
| 11:00 | Review account security, password and MFA requirements, device care, file handling, and client confidentiality. Explain how to report a security concern. | IT or Operations |
| 11:30 | Give an overview of the agency: services, team structure, current priorities, working norms, and how projects move from brief to delivery. | Manager |
| 12:30 | Have lunch with the team or buddy. Keep it informal and make sure the new hire knows whom to contact with questions. | Buddy or manager |
| 1:30 | Walk through the role’s responsibilities, near-term goals, communication preferences, and how feedback and approvals work. Share the relevant project folders and templates. | Manager |
| 2:30 | Arrange introductory meetings with key collaborators and explain who handles common requests, such as resourcing, expenses, IT support, and client questions. | Manager |
| 3:30 | Give the new hire a small, low-risk first task or guided practice exercise. Confirm the brief, deadline, and review contact; do not assign unsupervised client-critical work on day one. | Manager |
| 4:30 | Check in: ask what is clear or confusing, resolve immediate blockers, recap the next day’s plan, and confirm the new hire has everything needed to leave or log off comfortably. | Manager |

*Adjust the times to fit the agency’s schedule. For remote hires, replace in-person tours and introductions with video calls and links to shared resources.*

## First-day checklist

### People/Operations
- [ ] Confirm start details, schedule, and welcome contact.
- [ ] Prepare workspace, equipment, and required forms.
- [ ] Complete employment and policy paperwork.
- [ ] Share the handbook and explain how to get help.

### IT/Operations
- [ ] Provide the computer and required accessories.
- [ ] Set up and test role-appropriate accounts and tools.
- [ ] Confirm MFA and basic security guidance.
- [ ] Explain how to request support and report a security issue.

### Manager or buddy
- [ ] Welcome the new hire and make introductions.
- [ ] Explain agency structure, working norms, and project workflow.
- [ ] Review role expectations and near-term goals.
- [ ] Share relevant folders, templates, and communication channels.
- [ ] Assign a suitable first task with a clear brief and reviewer.
- [ ] Hold an end-of-day check-in and confirm tomorrow’s plan.

### New hire
- [ ] Complete required forms and acknowledgments.
- [ ] Sign in to the tools needed for the role.
- [ ] Ask questions and note any access or equipment issues.
- [ ] Confirm the next day’s start time and priorities.
