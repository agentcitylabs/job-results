# SOP-ONB-01: New Hire First Day — Small Design Studio

**Document owner:** Studio Manager  
**Version:** 1.0  
**Applies to:** All full-time and contract design hires, in-studio or remote  
**Day-of timing:** Based on a 9:00–17:00 studio day. Adjust times to your actual hours.

---

## 1. Purpose

Get a new hire oriented, set up with tools, and connected to the team without making them sit through a generic HR deck. The goal is that by 17:00 they have touched one real project, know who to ask for help, and can find the bathroom without asking twice.

---

## 2. Roles

| Role | Who it is | Responsibility |
|---|---|---|
| Studio Manager (SM) | Office manager, people ops, or studio coordinator | Owns the day, prepares the space and paperwork, removes blockers |
| Design Lead (DL) | Hiring manager, usually a senior designer or creative director | Sets project context, assigns first task, checks in on fit and clarity |
| Buddy | Assigned peer, same discipline or one level up | Social anchor, tool walkthrough, lunch, debrief |
| New Hire (NH) | The person starting | Shows up, asks questions, completes setup and first task |

If you are a very small studio, the Studio Manager and Design Lead may be the same person. In that case, the Buddy should take over the physical welcome and tour so the new hire still sees two friendly faces before lunch.

---

## 3. Materials to Prepare Before 9:00

- [ ] Desk cleaned, chair adjusted, monitor/keyboard/mouse tested
- [ ] Welcome kit: notebook, pen, water bottle, agency sticker pack, one small non-corporate item such as a local coffee card
- [ ] Badge or key card activated
- [ ] Payroll, tax, and direct deposit forms printed or sent electronically
- [ ] Emergency contact form ready
- [ ] Accounts created and tested: email, Slack, Figma, Adobe Creative Cloud, password manager, time tracking tool
- [ ] Shared drive and project folders shared with correct permissions
- [ ] Calendar invite with the day’s schedule sent to NH, SM, DL, and Buddy
- [ ] Lunch plan confirmed — reservation, order, or delivery
- [ ] Day 2 plan drafted

---

## 4. First Day Steps

| Time | Step | Owner | What to do / say |
|---|---|---|---|
| 8:30–8:50 | Pre-arrival check | SM | Unlock studio, turn on lights, set out welcome kit, test logins one final time. Send a Slack message to the team: “New hire arrives at 9 — please be ready to say hi.” |
| 9:00–9:15 | Arrival and welcome | SM | Greet NH at the door. Offer coffee or tea. Walk them to their desk. Point out restrooms, kitchen, fire exits, and where to put a lunch. Do not hand them a 40-page handbook yet. |
| 9:15–9:45 | Paperwork and account setup | SM + IT/Ops | Complete payroll, tax, emergency contact, and policy sign-off. Have NH log in to email, Slack, password manager, and time tracking. Verify they can access the shared drive. If any account fails, Buddy takes NH on a studio tour while SM fixes it. |
| 9:45–10:15 | Team introductions | Buddy | Walk NH around the studio or through a short video call. Introduce each person with one concrete line: “Mira leads brand identity. She’s the reason our packaging work doesn’t look like everyone else’s.” Add NH to Slack channels: #general, #design, #random, and any active project channels. |
| 10:15–11:00 | Project and file overview | DL | Give a 30-minute walkthrough of active projects. Use one real client example. Show the file structure, naming conventions, and where work lives. Open a live Figma file and point out what “good” looks like. Grant NH view or comment access to relevant files. |
| 11:00–11:30 | Brand and process basics | Buddy | Show brand guidelines, design system, templates, and the project management board. Explain how to log time daily, where to ask questions, and how to request assets. Keep this practical, not a lecture. |
| 11:30–12:30 | Lunch | Buddy | Buddy takes NH to lunch, agency pays. First 20 minutes: no shop talk. Then answer questions the NH was too polite to ask in the studio. |
| 12:30–13:30 | First small task | DL | Assign a low-stakes, useful task. Examples: audit one section of a Figma file for naming inconsistencies, update component labels, or read a client brief and write three clarifying questions. The point is to touch real work without pressure. |
| 13:30–14:00 | Check-in with DL | DL | 15-minute one-on-one. Ask: What made sense? What felt unclear? What do you need tomorrow? Listen more than you talk. |
| 14:00–15:00 | Shadow or observe | Buddy | Include NH in a meeting or design review as an observer. Give context before the meeting and debrief for five minutes after. NH should not present or take notes unless asked. |
| 15:00–15:30 | Studio ops and norms | SM | Cover communication norms, meeting etiquette, file saving rules, time off, expenses, and security basics. Show where the first aid kit and emergency contacts live. |
| 15:30–16:00 | Workspace setup | NH | NH adjusts desk, monitor, chair, downloads fonts, sets Slack notifications, and bookmarks key links: project board, brand hub, shared drive, time tracking. Buddy stays nearby for quick questions. |
| 16:00–16:30 | End-of-day recap | SM + Buddy + NH | Review the checklist together. Collect feedback on what would have made the day smoother. Confirm next day start time and first task. |
| 16:30–17:00 | Wrap-up | SM | NH reads the onboarding doc and signs off. SM sends a welcome email with links, the Day 2 plan, and a note that the Buddy will check in the next morning. |

## 5. First Day Checklist

Print this or use it as a shared digital checklist. Physically ticking boxes is more satisfying.

### Studio Manager

- [ ] Desk and equipment tested
- [ ] Welcome kit placed
- [ ] Badge/key card activated
- [ ] Payroll and tax forms ready
- [ ] Emergency contact form ready
- [ ] All accounts created and tested
- [ ] Shared drive and project folders shared
- [ ] Calendar invite sent
- [ ] Lunch planned
- [ ] Day 2 plan drafted
- [ ] Welcome email sent at end of day

### Design Lead

- [ ] Project overview prepared with one real example
- [ ] First small task scoped and ready
- [ ] Relevant files shared with view/comment access
- [ ] 15-minute check-in scheduled
- [ ] Meeting or review identified for shadowing

### Buddy

- [ ] Welcome message sent in Slack
- [ ] Team intro route planned
- [ ] Brand guidelines and design system links ready
- [ ] Lunch confirmed
- [ ] Debrief questions prepared

### New Hire

- [ ] Badge/key received
- [ ] Email and Slack logged in on laptop and phone
- [ ] Figma and Adobe logged in
- [ ] Profile photo and title set
- [ ] Joined #general, #design, #random, and relevant project channels
- [ ] Time tracking tool logged in
- [ ] Password manager set up
- [ ] Emergency contact submitted
- [ ] Direct deposit submitted
- [ ] Read code of conduct and security policy
- [ ] Bookmarked key links
- [ ] Met all team members
- [ ] Understood first task and where to ask questions
- [ ] Confirmed next day start time

---

## 6. If Something Goes Wrong

- **Account access breaks:** Buddy shadows NH on design work or file review while SM fixes access. Do not make NH sit idle.
- **Design Lead is unavailable:** Buddy covers the project overview using the DL’s prepared notes. DL reschedules the check-in for the next morning.
- **New hire is remote:** Replace the studio tour with a screen-share tour of your digital spaces — Slack channels, Figma projects, shared drive, and project board. Ship the welcome kit in advance. Keep the same order and timing.
